# \# Задание 3: Шпаргалка статус-кодов HTTP

# 

# Статус-коды — это трехзначные числа, с помощью которых сервер сообщает клиенту о результате выполнения его запроса.

# 

# \### Основные группы кодов:

# \* \*\*1xx (Информационные):\*\* Процесс идет, сервер продолжает обрабатывать запрос.

# \* \*\*2xx (Успешно):\*\* Всё прошло отлично, запрос выполнен (например, \*\*200 OK\*\*).

# \* \*\*3xx (Перенаправление):\*\* Нужный ресурс перемещен, вас перенаправляют на другую страницу (например, \*\*301 Moved Permanently\*\*).

# \* \*\*4xx (Ошибка клиента):\*\* Ошибка на стороне пользователя (например, \*\*404 Not Found\*\* — страница не существует, или \*\*403 Forbidden\*\* — нет доступа).

# \* \*\*5xx (Ошибка сервера):\*\* Что-то сломалось на самом сервере (например, \*\*500 Internal Server Error\*\* или \*\*502 Bad Gateway\*\*).
