# Задание 3: Шпаргалка статус-кодов HTTP

Статус-коды — это трехзначные числа, с помощью которых сервер сообщает клиенту о результате выполнения его запроса.

### Основные группы кодов:
* **1xx (Информационные):** Процесс идет, сервер продолжает обрабатывать запрос.
* **2xx (Успешно):** Всё прошло отлично, запрос выполнен (например, **200 OK**).
* **3xx (Перенаправление):** Нужный ресурс перемещен, вас перенаправляют на другую страницу (например, **301 Moved Permanently**).
* **4xx (Ошибка клиента):** Ошибка на стороне пользователя (например, **404 Not Found** — страница не существует, или **403 Forbidden** — нет доступа).
* **5xx (Ошибка сервера):** Что-то сломалось на самом сервере (например, **500 Internal Server Error** или **502 Bad Gateway**).
500 Internal Server Error (Внутренняя ошибка): Общий сбой в работе сайта. Что-то сломалось в коде или базе данных.
502 Bad Gateway (Плохой шлюз): Один сервер в цепочке не смог получить ответ от другого.
503 Service Unavailable (Сервис недоступен): Сервер перегружен или на нем идут технические работы.
504 Gateway Timeout (Время истекло): Сервер слишком долго ждал ответа от вспомогательного сервера
400 Bad Request (Плохой запрос): Запрос составлен с ошибкой, и сайт не понимает его.
401 Unauthorized (Не авторизован): Нужно войти в систему под своим логином и паролем.403 Forbidden (Доступ запрещен): У вас нет прав на просмотр этой страницы.
404 Not Found (Не найдено): Запрашиваемой страницы больше нет по этому адресу (удалена или не существовала).
429 too many request   Вы отправили слишком много запросов за короткое время (сработала защита от роботов).
